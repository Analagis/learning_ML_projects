In this project, the following methods and models were used:

* Simple Exponential Smoothing
* Holt and Holt–Winters Exponential Smoothing (trend and seasonal components)
* SARIMA / SARIMAX for per-area time series forecasting
* Gradient Boosting with LightGBM (global model across all areas)
* Temporal Convolutional Network (TCN) for one-step-ahead forecasting with recursive multi-step horizon
